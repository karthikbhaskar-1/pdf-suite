# Toolbar and status bar

## Menu bar

The menu bar is the row at the very top of the window. It has these menus:

- **File:** Open…, Open Recent, Save, Save As…, Extract Pages…, Combine Files…, Split into Files…, Close Tab, Close All, Document Properties…, Exit.
- **Edit:** Undo, Redo, Copy, Select All, Find…, Find Next, Find Previous, Go to Page…, Command Palette….
- **View:** Zoom In, Zoom Out, Actual Size (100%), Fit Page, Fit Width, Rotate View, Split, Loupe, Pan and Zoom, Panels, Page Colors, Theme, Toolbar, Full Screen.
- **Pages:** the page commands, see [Organizing pages](organizing-pages.md).
- **Window:** Next Tab, Previous Tab, and a list of open tabs. An open tab with unsaved changes has a dot (•) beside it.
- **Help:** Keyboard Shortcuts…, Open Logs Folder, About PDF Suite….

Menu items that cannot be used right now are greyed out. They stay visible.

Checked items show a tick. Radio items show a dot, and only one can be chosen at a time.

### Keyboard for the menu bar

- Press **Alt** or **F10** to move to the menu bar.
- Press **F**, **E**, **V**, **P**, **W** or **H** to open File, Edit, View, Pages, Window or Help.
- Use the **Left** and **Right** arrow keys to move between menus, and **Up** and **Down** to move within one.
- Press **Enter** to choose an item.
- Press **Esc** to close the menu. Focus goes back to the page.

## Title

The menu bar shows the file name and "PDF Suite" in the middle. A dot (•) after the file name means there are unsaved changes. The same text is shown in the taskbar.

## Toolbar

The toolbar is the row of icons under the tabs. Hover over an icon to see its name and shortcut. The tip appears after half a second.

Groups are separated by a thin line. The toolbar groups are File, Nav, View, Pages, Find and Theme.

To show the labels next to the icons, choose View ▸ **Toolbar** ▸ **Show Labels**. This setting is off by default.

To hide the whole toolbar, choose View ▸ **Toolbar**.

### Buttons that stay visible

When the window is narrow, some buttons are moved under the **…** button. These buttons always stay visible:

- Open, Save, Undo, Redo
- Find
- Previous page, Next page and the page box
- Theme
- The **…** button itself

The order of moving is: lower priority buttons first (Pages More, Crop, Page size, Loupe, Pan and zoom, Page colors), then Recent, Rotate, Delete, Insert and Split.

Press **Tab** to reach **…**. Press **Enter** or **Down** to open it.

## Status bar

The status bar is the row at the bottom of the window.

- **Left:** "Page 3 of 12" with a box to type a page number. Press **Enter** to go to that page. Next to it is the document size and rotation. This text is cut short first when the window is narrow.
- **Right:** Fit Page, Fit Width, Zoom Out, the zoom percentage box, Zoom In, and an optional zoom slider.

The zoom box has a list: 50, 75, 100, 125, 150, 200 and 400 percent.

When the window is narrow, these are hidden, in this order: the zoom slider, then the document size and rotation, then Fit Page and Fit Width. The zoom percentage box and the page box always stay.

When a long job runs, a progress bar appears in the status bar with a **Cancel** button. See [Merge, split, cut and compare](merge-split-cut-compare.md).

## Keyboard shortcuts

| Action | Shortcut |
|---|---|
| Open | Ctrl+O |
| Save | Ctrl+S |
| Save As… | Ctrl+Shift+S |
| Close tab | Ctrl+W |
| Close all tabs | Ctrl+Shift+W |
| Next tab | Ctrl+Tab |
| Previous tab | Ctrl+Shift+Tab |
| Undo | Ctrl+Z |
| Redo | Ctrl+Y or Ctrl+Shift+Z |
| Copy | Ctrl+C |
| Select all | Ctrl+A |
| Find | Ctrl+F |
| Next match | F3 |
| Previous match | Shift+F3 |
| Go to page | Ctrl+G |
| Fit Page | Ctrl+0 |
| Fit Width | Ctrl+1 |
| Zoom in or out | Ctrl++ or Ctrl+- |
| Next page or previous page | Page Down or Page Up |
| Split screen | Ctrl+\\ |
| Switch pane | F6 |
| Command palette | Ctrl+K |
| Duplicate pages | Ctrl+D |
| Delete pages | Delete |
| Rotate right or left | Ctrl+Shift+R or Ctrl+Shift+L |
| Full screen | F11 |
| Move a thumbnail selection | Alt+Up or Alt+Down |
| Move to first or last thumbnail | Alt+Home or Alt+End |

Shortcuts cannot be changed yet. Customizing them is planned for a later version.

## Messages

| Message | What it means |
|---|---|
| Restored 3 tabs | PDF Suite reopened your tabs after the app closed unexpectedly. |
| Opened 3 files · Combine them… | You dropped several PDFs. Choose Combine them… to join them into one file. |
| Pictures and text files can't be opened on their own · Combine into a PDF… | You dropped pictures or text files. Combine them into a PDF first. |
| PDF Suite is still working on your files. Wait for it to finish, or cancel it. | A merge or split is running. Wait, or choose Cancel. |
