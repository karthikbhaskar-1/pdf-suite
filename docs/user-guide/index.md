# PDF Suite user guide

PDF Suite is a free PDF app for Windows. These pages show you how to use it.

This guide covers the Windows app. Shortcuts are given for Windows.

- [Organizing pages](organizing-pages.md): insert, delete, duplicate, replace, reverse, extract, rotate, crop, resize and reorder pages.
- [Toolbar and status bar](toolbar-and-status-bar.md): the menu bar, the toolbar, the status bar, and the messages you may see.

## Quick start

1. Press **Ctrl+O** and choose a PDF.
2. Read the file. Use the scroll wheel, **Page Down** and **Page Up** to move.
3. Press **Ctrl+S** to save your changes.

## Where to find things

PDF Suite has a menu bar at the top, then the tab strip, then the toolbar. The status bar is at the bottom. Panels open on the left side of the window.

If you do not know where a command is, press **Ctrl+K** to open the command palette. Type part of the name.
