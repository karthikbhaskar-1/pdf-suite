# Opening and viewing

## Open a file

- **Menu:** File ▸ **Open…**
- **Keyboard:** **Ctrl+O**
- **Toolbar:** Open
- **Drag and drop:** drag one or more PDF files onto the main window.
- **Recent files:** File ▸ **Open Recent** lists the last 10 files. Choose **Clear List** to empty it.

When no file is open, the empty screen shows an **Open PDF** area and your recent files.

Each file opens in its own tab. If you drop two or more PDFs at once, PDF Suite shows: "Opened 3 files · Combine them…"

### Messages when a file does not open

| Message | What it means |
|---|---|
| This file is damaged. | The file is broken and cannot be read. |
| This isn't a PDF. | The file is not a PDF. |
| This file is empty. | The file has no data. |
| This file needs a password. | The file is locked, and no password was given. |
| Wrong password, try again. | The password you typed is not right. Type it again. |
| This file was moved, renamed or deleted. | The file is no longer in its place. |
| This file could not be read. | The file is there, but PDF Suite could not read it. |
| This file is too large to open (the limit is 1 GB). | The file is bigger than 1 GB, so it is not opened. |

A file that needs a password shows a password prompt. This is the only pop-up window that appears while you read a file.

A file up to 1 GB opens. A file over 500 MB opens for viewing only, so you can read and search it but not edit it. See [Large files](saving-recovery-and-file-safety.md#large-files).

Forms that are built in a format called XFA can be viewed, but not edited yet. Organizing commands are off for them, with the tooltip "This form can be viewed but not edited yet."

## Move around

- **Scroll:** mouse wheel, or the scroll bar.
- **Next and previous page:** the arrows in the toolbar, or **Page Down** and **Page Up**.
- **Go to a page:** **Ctrl+G**, or type a page number in the page box in the toolbar or status bar.
- **Thumbnails:** click a thumbnail to jump to that page.

While the file loads, a progress bar shows. The first page appears early, and the rest follow.

## Zoom

- **Zoom in and out:** **Ctrl +** and **Ctrl −**, or the buttons in the status bar.
- **Zoom with the wheel:** hold **Ctrl** and turn the wheel. The zoom centers on the mouse pointer.
- **Fit Page:** **Ctrl+0**, or View ▸ **Fit Page**.
- **Fit Width:** **Ctrl+1**, or View ▸ **Fit Width**.
- **Actual Size (100%):** View ▸ **Actual Size (100%)**.
- **Zoom percentage:** type a number in the zoom box in the status bar, or pick one from its list: 50, 75, 100, 125, 150, 200 or 400.

## Tabs

- **Next tab:** **Ctrl+Tab**
- **Previous tab:** **Ctrl+Shift+Tab**
- **Close a tab:** **Ctrl+W**, or the close button on the tab.
- **Close all tabs:** **Ctrl+Shift+W**, or File ▸ **Close All**.
- **Tab right-click menu:** Close tab, Close other tabs, Close tabs to the right, Duplicate, Open in split, Copy path.

If you close the last tab, the empty screen appears. If you closed tabs before a crash, PDF Suite shows "Restored 3 tabs" (the number changes) when it starts again.

## Split the screen

Split shows two parts of one file, or two different files, side by side. Scrolling is linked, so the two panes move together.

- **Menu:** View ▸ **Split** ▸ **None**, **Vertical** or **Horizontal**
- **Keyboard:** **Ctrl+\\** to split. **F6** to switch to the other pane.
- **Divider:** drag it to change the size of the panes. The divider also has a button that turns the linked scrolling on or off.
- **Choose a file for a pane:** each pane has its own file picker, page and zoom.

## Loupe and Pan and zoom

- **Loupe** is a small magnifier window. It uses the same page colors as the pages.
- **Pan and zoom** is a small window that shows an overview of the document, so you can move quickly around a large file.

Both windows can be moved and closed. They remember their position and size. Press **Esc** to close the window that has focus.

To turn them on or off, use View ▸ **Loupe** or View ▸ **Pan and zoom**, or the buttons in the toolbar.

## Colors and themes

- **Theme:** View ▸ **Theme** ▸ **System**, **Light** or **Dark**.
- **Page colors:** View ▸ **Page Colors** ▸ **Off**, **Invert**, **Sepia**, **Night**, **High contrast** or **Custom**. Custom gives you two color pickers: one for the background and one for the text.

Page colors change how pages look on screen. They do not change the file.

## Rotate the view

Rotate View turns the screen image of a page. It does not change the file.

- **Menu:** View ▸ **Rotate View** ▸ **Clockwise** or **Counter-clockwise**
- **Right-click:** on a page, choose **Rotate view**.

## Page right-click menu

Right-click a page to see: Copy, Select all, Zoom, Fit width, Rotate view, Split here, Page colors, Properties and Pages.
